## Commands
- Відкрити `index.html` у браузері для локального перегляду сайту.
- Збірка проєкту не потрібна.

## Conventions
- Перед внесенням змін у файл запитувати підтвердження.
- Після внесення змін у файл автоматично зберігати його; для інших дій запитувати підтвердження.
- Пропозиції щодо змін пояснювати українською мовою.
- Якщо в запиті є додаткові вимоги, виконувати їх з урахуванням цих правил.

## Architecture
Навчальний тестовий репозиторій Mate Academy.
Статична HTML-сторінка, що публікується через GitHub Pages.

### Структура проєкту
- `index.html` — головна сторінка сайту.
- `README.md` — опис репозиторію.
- `Maska.gitignore` — шаблон ігнорованих файлів.
- `CLAUDE.md` — інструкції для Claude Code.

### Гілки
- `main` — основна гілка.
- `gh-pages` — гілка, з якої публікується сайт.
