# Myron.mate-test-repository

## Опис проєкту
Навчальний тестовий репозиторій (Mate academy). Статична HTML-сторінка,
що публікується через GitHub Pages (гілка `gh-pages`).

## Структура
- `index.html` — головна сторінка сайту
- `README.md` — опис репозиторію
- `Maska.gitignore` — шаблон ігнорованих файлів
- `CLAUDE.md` — інструкції для Claude Code

## Гілки
- `main` — основна гілка
- `gh-pages` — гілка, з якої публікується сайт

## Запуск
Збирати нічого не треба: відкрийте `index.html` у браузері.

## Правила роботи
- Перед змінами у файлі запитувати підтвердження.
- Після змін зберігати файл автоматично; на інші дії запитувати підтвердження.
- Пропозиції змін пояснювати українською мовою.
- Якщо в запиті є інші вимоги, виконувати запит з урахуванням цих вимог.
